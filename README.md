## 高性能VPS的性能，到底看什么

一台VPS的性能上限，基本由四个指标决定，买之前逐项对照，能过滤掉大部分营销话术。

**虚拟化架构**。现在的生产环境几乎清一色KVM：真硬件虚拟化、独立内核、独占内存，宿主机内核出问题也不会波及你的实例。OpenVZ这类容器方案如今只在最低价位段还能见到，下单前先确认架构，这一项不过关，后面都不用看。

**CPU分配方式**。共享核便宜，但邻居一忙你就跟着卡；专属核贵一档，换来的是全天候稳定的算力，这类产品一般叫VDS，比如Contabo的Max Performance VDS，€31.20/月起给6到24个专属EPYC核心。

**存储**。SATA SSD的顺序读写卡在550MB/s，而PCIe 4.0的NVMe能扛住25万次以上的4K随机IOPS，数据库、Redis这类应用对差距感知最明显。

**网络**。1Gbps端口是当下主流配置，真正拉开差距的是月流量额度和线路质量，后者只能实测。
